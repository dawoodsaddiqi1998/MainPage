Teaching & Assessment Plan

60-Day Front-End Web Development & AI Course Plan

Each day follows the same six-part teaching template: Learning Outcome, Learning Activities, Assessment, Employability Link, Portfolio Evidence, and Transferable Skills.

60 teaching days
11 modules
6 planning elements per day

How to use this plan

This document expands the supplied 60-day course outline into a consistent classroom planning format. Teachers can use each day as a lesson-plan summary, assessment guide, employability reference, and portfolio-evidence checklist.

Day 1

Foundations & Orientation

Module 0 — Getting Started

1 Learning Outcome

Students will be able to use basic computer, internet, email, and online-safety skills; explain how websites work; and identify the roles of HTML, CSS, and JavaScript.

2 Learning Activities

Teacher demonstrates computer fundamentals, browsers, effective searching, Gmail, online safety, client/server concepts, and the front-end development path. Students practice file/folder management, web searching, email use, and identifying front-end vs back-end examples.

3 Assessment

Can students safely use the computer and internet, send a professional email, and explain in simple terms how a website works?

4 Employability Link

Digital literacy, safe online behavior, and understanding the web are basic requirements for study, office work, and entry-level technology jobs.

5 Portfolio Evidence

Create a one-page learning map showing the web-development path, key tools, and basic online-safety rules.

6 Transferable Skills

Digital literacy, communication, problem-solving, self-directed learning

Day 2

Dev Setup & HTML Basics

Module 1 — HTML & CSS

1 Learning Outcome

Students will be able to prepare a front-end development environment and create a correctly structured HTML5 page using elements, tags, and attributes.

2 Learning Activities

3 Assessment

Can students create, save, run, and correctly structure a valid HTML5 page in VS Code?

4 Employability Link

Developers must be able to configure their tools and create clean, readable HTML files for real web projects.

5 Portfolio Evidence

Create a first personal HTML page with title, headings, paragraphs, and correct HTML5 structure.

6 Transferable Skills

Attention to detail, digital organization, independent learning
