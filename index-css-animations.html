The big idea

Animations run through defined stages

A CSS animation connects an element to a named set of keyframes. Unlike a transition, it can start automatically, contain many stages, repeat, reverse, pause, and continue without another state change.

↔

Transition

Usually needs a property change such as hover, focus, or a class added with JavaScript.

∞

Animation

Can run automatically, repeat forever, and move through any number of keyframe stages.

Mental model: @keyframes describes the timeline. The animation properties describe how the element plays that timeline.
Question Transition Animation
Needs a trigger? Usually yes No; it can start on page load
Number of stages Usually start and end Any number from 0% to 100%
Can repeat? Only after another state change Yes, with a count or infinite
Can pause? Not with a dedicated property Yes, using animation-play-state

Create the timeline

Define motion with @keyframes

Give the animation a name, define its visual stages, then assign that name to an element.

Your first CSS animation
CSS 
@keyframes bounce {
  from {
    transform:
      translateY(30px)
      rotate(-4deg);
  }

  to {
    transform:
      translateY(-30px)
      rotate(4deg);
  }
}

.box {
  animation:
    bounce 1.4s
    ease-in-out infinite alternate;
}

Use percentages for multiple stages

Percentages show where each state occurs during one animation cycle. You do not need to list every percentage; the browser calculates the values between keyframes.

Three-stage timeline
CSS 
@keyframes journey {
  0% {
    left: 0;
    transform: rotate(0) scale(1);
  }

  50% {
    left: 50%;
    transform: rotate(180deg) scale(1.25);
  }

  100% {
    left: 100%;
    transform: rotate(360deg) scale(1);
  }
}
0% → 50% → 100%

3

Control playback

The eight main animation properties

These properties select the timeline and control its speed, repetition, direction, delay, final state, and playback status.

animation-name

The name written after @keyframes.

animation-duration

How long one complete cycle takes.

animation-timing-function

How the speed changes during each segment.

animation-delay

How long to wait before beginning. It can be negative.

animation-iteration-count

Number of cycles: 1, 3, or infinite.

animation-direction

Normal, reverse, alternate, or alternate-reverse.

animation-fill-mode

Styles applied before and after the active animation.

animation-play-state

Switches playback between running and paused.

Animation shorthand

name duration timing-function delay iteration-count direction fill-mode play-state
Shorthand and longhand
CSS 
/* Shorthand */
.box {
  animation:
    bounce 1.5s ease-in-out
    200ms 3 alternate both running;
}

/* Equivalent longhand */
.box {
  animation-name: bounce;
  animation-duration: 1.5s;
  animation-timing-function: ease-in-out;
  animation-delay: 200ms;
  animation-iteration-count: 3;
  animation-direction: alternate;
  animation-fill-mode: both;
  animation-play-state: running;
}
⏱
A duration is required for visible motion The default animation-duration is 0s, so an animation with only a name appears not to run.

Timing functions

Change the feeling of movement

Each racer below runs for exactly two seconds. Only its timing function changes.

Easing race

Notice acceleration, deceleration, and stepped movement.

linear

Constant speed. Useful for spinners, marquees, and mechanical motion.

ease-out

Fast response with a soft ending. Useful for elements entering a screen.

steps()

Jumps between fixed states. Useful for sprite sheets and typing cursors.

⏪
Negative delays begin partway through animation-delay: -2s makes the animation appear as if it started two seconds earlier.

Pause and restart

Control animations with CSS and JavaScript

Use animation-play-state to pause without losing the animation’s current position.

Pause and resume
CSS + JavaScript 
.spinner {
  animation: spin 2.5s linear infinite;
}

.spinner.paused {
  animation-play-state: paused;
}

button.addEventListener("click", () => {
  spinner.classList.toggle("paused");
});
Live control
RUN

Restart an animation

Remove the animation class, force the browser to recalculate layout, then add the class again.

Reliable replay pattern
JavaScript 
element.classList.remove("animate");
void element.offsetWidth; // force reflow
element.classList.add("animate");

Multiple animations and events

Combine timelines and detect lifecycle events

Multiple animations

Separate animations with commas. The first name uses the first duration, timing function, and other values; the second uses the second values.

Three animations on one element
CSS 
.box {
  animation:
    float 2s ease-in-out infinite alternate,
    color-change 4s linear infinite,
    morph 3s ease-in-out infinite alternate;
}

Performance and accessibility

Common mistakes to avoid

1

Forgetting the duration

The default duration is zero seconds, making the change invisible.

animation: bounce 1s ease;
2

Using the wrong keyframe name

animation-name must exactly match the name after @keyframes.

@keyframes pulse { ... } → animation-name: pulse;
3

Animating expensive layout properties

Prefer transform and opacity for smooth interface motion.

transform: translateX(100px); opacity: 0;
4

Too many infinite animations

Constant movement can distract users, consume resources, and weaken visual hierarchy.

Use infinite only when continuous motion communicates status.
5

Expecting the last keyframe to remain automatically

Use animation-fill-mode: forwards or set the final state in the base class.

animation: enter 500ms ease-out forwards;
6

Ignoring reduced-motion preferences

Provide a low-motion experience for users who request it.

@media (prefers-reduced-motion: reduce) { ... }

Accessible reduced-motion pattern

Reduce non-essential motion
CSS 
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
  }
}

Practice and review

Test your understanding

Try each exercise before opening its answer. Then edit this file and create your own variation.

Exercise 1: Rotate an element continuously once per second.
@keyframes spin { to { transform: rotate(360deg); } } .box { animation: spin 1s linear infinite; }
Exercise 2: Run an animation forward, then backward, forever.
Use animation-iteration-count: infinite and animation-direction: alternate.
Exercise 3: Keep the final keyframe after a one-time entrance animation.
Use animation-fill-mode: forwards, or the shorthand animation: enter 500ms ease-out forwards;.
Exercise 4: Start an animation halfway through its cycle.
Use a negative delay. For a four-second animation, animation-delay: -2s starts at approximately the halfway point.
Exercise 5: Why is steps() different from linear?
linear changes continuously at a constant speed. steps() jumps between a fixed number of discrete states.
Exercise 6: Pause an animation without resetting its current position.
Set animation-play-state: paused. Return it to running to continue from the same point.

CSS animation cheat sheet

@keyframes name { from { ... } to { ... } } animation: name 1s ease 0s 1 normal none running; animation-iteration-count: infinite; animation-direction: alternate; animation-fill-mode: both; animation-play-state: paused; animation-delay: -500ms; animation-timing-function: steps(5, end);
