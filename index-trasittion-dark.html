Begin here

Two properties, two different jobs

A transform describes the visual change. A transition describes how smoothly the browser moves from the old value to the new value.

⏱

Transition = how it changes

Controls the property, duration, speed curve, and optional delay.

transition: transform 0.3s ease;
↗

Transform = what changes

Moves, rotates, scales, skews, or changes the 3D angle of an element.

transform: scale(1.1);
💡
The simplest mental model transform creates the destination; transition creates the journey.
2

CSS transition

Turn an instant change into a smooth change

A transition runs only when an animatable CSS property changes—for example because of :hover, :focus, :active, or a class added with JavaScript.

Basic transition
HTML + CSS 
<button class="color-button">
  Hover me
</button>

.color-button {
  background-color: blue;
  transition:
    background-color 1s ease,
    transform 1s ease;
}

.color-button:hover {
  background-color: tomato;
  transform: scale(1.08);
}
Live result

Move the pointer over the button.

Transition shorthand

property duration timing-function delay 
transition: transform 500ms ease-out 100ms;
transform

The CSS property whose value will change smoothly.

500ms

How long the change takes. 1000ms equals one second.

ease-out

The speed curve. This example moves quickly, then slows down.

100ms

How long the browser waits before starting the transition.

Longhand form

Same transition, written separately
CSS 
.box {
  transition-property: transform;
  transition-duration: 500ms;
  transition-timing-function: ease-out;
  transition-delay: 100ms;
}

Multiple properties

Separate multiple transitions with commas. Explicit property names are usually safer than transition: all.

Different settings for different properties
CSS 
.card {
  transition:
    transform 300ms ease,
    background-color 500ms linear,
    box-shadow 300ms ease;
}

Duration, easing, delay

Control how motion feels

Two transitions can have the same duration but feel completely different because their timing functions accelerate and decelerate differently.

Use linear

For constant mechanical motion, progress indicators, or endless rotation.

Use ease-out

For elements entering the screen or responding quickly to a user.

Use ease-in-out

For movement that has a clear beginning and ending on the screen.

CSS transform

Move, resize, rotate, and slant

Transforms change how an element is painted without normally moving other elements in the document. Hover each example to see its result.

Translate

Moves an element along the X and/or Y axis.

translate(62px, -14px)
MOVE

Scale

Makes an element visually larger or smaller.

scale(1.42)
SIZE

Rotate

Turns an element around its transform origin.

rotate(135deg)
TURN

Skew

Slants an element along the X or Y axis.

skewX(-20deg)
SLANT

translateX()

Positive values move right; negative values move left.

translateY()

Positive values move down; negative values move up.

scaleX()

Changes only the visual width of the element.

scaleY()

Changes only the visual height of the element.

📐
Percentages in translate are based on the element itself If a box is 200px wide, translateX(50%) moves it approximately 100px.
🔄
Rotation can use different angle units rotate(180deg), rotate(0.5turn), and rotate(3.1416rad) describe approximately the same half-turn.

Combination, order, origin, 3D

Advanced transform behavior

Combine several transform functions

Write every function in one transform declaration. A later transform declaration replaces an earlier one. 

transform:
  translateY(-10px)
  rotate(5deg)
  skewX(-3deg)
  scale(1.05);

Order matters

Swapping the order can change the final path because each function changes the coordinate system used by the next calculation. Hover both cards.

transform-origin and 3D perspective

The origin is the point around which rotation and scaling occur. Perspective makes X- and Y-axis rotation look three-dimensional.

Door hinge

transform-origin: left center;
DOOR

3D card

🔭
Perspective distance Smaller values such as 300px create a stronger 3D effect. Larger values such as 1200px create a softer effect.

8

Rules and common mistakes

Avoid these problems

1

Put the transition on the normal state

This lets the element animate both when entering and leaving hover.

.button { transition: transform 300ms ease; }
2

display does not transition smoothly

For reveals, use combinations of opacity, visibility, and transform.

opacity: 0; transform: translateY(-10px);
3

Transforms do not normally change layout flow

A transformed element moves visually, but its original space remains reserved.

Use Grid/Flexbox for layout; use transform for visual movement.
4

Do not overwrite earlier transforms

Two separate declarations do not combine; the second one wins.

transform: translateX(50px) rotate(20deg);
5

Prefer explicit properties over all

It prevents accidental animation of expensive or unexpected properties.

transition: transform 300ms ease, opacity 300ms ease;
6

Prefer transform and opacity for smooth motion

They usually perform better than repeatedly changing top, left, width, or height.

transform: translateX(100px); opacity: 0;

Respect reduced-motion preferences

Accessibility pattern
CSS 
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}

Transition versus animation

Question Transition Animation
What starts it? A state or property change Can start automatically
How many main states? Usually start and end Many stages with @keyframes
Can it repeat? Only after repeated state changes Yes, with infinite or a count
Best use Hover, focus, opening, selection Loaders, loops, multi-step sequences

Check your understanding

Practice and review

Try each task before opening its solution. Modify this file directly to experiment further.

Exercise 1: Move a box 100px right over two seconds.

Solution:

.box { transition: transform 2s ease; } .box:hover { transform: translateX(100px); }
Exercise 2: Enlarge an image without letting it escape its frame.

Solution: Put overflow: hidden on the frame and transform: scale(1.15) on the image during hover.

Exercise 3: Why should the transition normally be outside :hover?

So the browser can use it when moving to the hover state and when returning to the normal state.

Exercise 4: Combine upward movement, rotation, and enlargement.
transform: translateY(-10px) rotate(4deg) scale(1.06);
Exercise 5: Which properties are usually best for smooth interface motion?

transform and opacity are usually the best starting point.
